# ჩაკა — სამედიცინო პორტალი

ეს არის ჩემი საფინალო პროექტი Skillwill-ის Front-end კურსზე. გავაკეთე სამედიცინო ვებ-პორტალი, სადაც შეგიძლია სიმპტომების მიხედვით გაარკვიო რომელ ექიმთან წახვიდე, დაჯავშნო ვიზიტი, ნახო კლინიკები რუკაზე, გამოიყენო კალკულატორები, გაიგო რას ნიშნავს შენი ანალიზი და ინტერნეტის გარეშეც გახსნა პირველადი დახმარების ინსტრუქციები.

ყველაფერი დავწერე **მხოლოდ HTML-ით, CSS-ით და ჩვეულებრივი JavaScript-ით** — არც ფრეიმვორკი და არც ბიბლიოთეკა არ გამომიყენებია.

> ⚠ ეს სასწავლო პროექტია. ექიმები, პარტნიორი ბრენდები და სტატისტიკა გამოგონილია (დემოა), კლინიკების ადგილმდებარეობა მიახლოებითია.
> საიტი **დიაგნოზს არ სვამს** და ექიმს ვერ ჩაანაცვლებს. გადაუდებელ შემთხვევაში დარეკე **112**.

## როგორ გავუშვა

ბილდი არ სჭირდება. საკმარისია `index.html` გახსნა ბრაუზერში. თუ გინდა ოფლაინ რეჟიმიც სცადო, საიტი სერვერიდან უნდა გაიხსნას (Service Worker ჩვეულებრივ ფაილად გახსნისას არ მუშაობს):

```
python3 -m http.server
```

და ბრაუზერში `http://localhost:8000`.

## რა ფუნქციები აქვს

- **სიმპტომების რუკა:** სხეულზე ირჩევ ადგილს, შემდეგ სიმპტომებს და საიტი გეუბნება რამდენად სასწრაფოა და რომელი სპეციალისტი გჭირდება.
- **ექიმები და ჯავშანი:** ძებნა, ფილტრი, დალაგება. ჯავშნის ფორმას აქვს ვალიდაცია, ჯავშნები ინახება `localStorage`-ში, შეიძლება გაუქმება და კალენდარში დამატება (`.ics` ფაილი).
- **კლინიკების რუკა:** რუკა თვითონ დავხატე SVG-ით (zoom, გადაადგილება, კლასტერები). „ჩემთან ახლოს“ ღილაკი Geolocation-ით ალაგებს კლინიკებს მანძილის მიხედვით.
- **ჯანმრთელობის დღიური:** წონა, წნევა, პულსი; გრაფიკი canvas-ზე დავხატე ბიბლიოთეკის გარეშე; არის CSV ექსპორტი.
- **ფორმები:** საკუთარი ვალიდაცია (სავალდებულო ველები, ელ-ფოსტა, ქართული მობილურის ფორმატი `5XX XX XX XX`), შეცდომის ტექსტი ველის ქვეშ.
- **კალკულატორები:** BMI, კალორიები, ჯანსაღი წონა, წელი/ბარძაყი, სხეულის ცხიმი, BSA, წყლის ნორმა, პულსის ზონები, არტერიული წნევა, ძილის ციკლები, მშობიარობის თარიღი, eGFR.
- **პირველადი დახმარება:** CPR მეტრონომით, ინსულტის ნიშნები (FAST), გაჩხირვა, სისხლდენა, დამწვრობა.
- **ბიბლიოთეკა** სტატიებით და „მითი თუ ფაქტი“.
- **ორი ენა** (ქართული და ინგლისური) და **ბნელი/ნათელი თემა**.
- **ანიმაციები:** ანიმირებული ლოგოები და canvas ეფექტები; მათ ვთიშავ, თუ მომხმარებელს ანიმაციები გამორთული აქვს (`prefers-reduced-motion`).

### ბოლოს დამატებული ახალი ფუნქციები

**ანალიზის ახსნა (`labs.html`).** 15 ანალიზია: ჰემოგლობინი, ლეიკოციტები, თრომბოციტები, გლუკოზა, HbA1c, ქოლესტერინი (საერთო, LDL, HDL), ტრიგლიცერიდები, კრეატინინი, ALT, TSH, ფერიტინი, ვიტამინი D და CRP. შეიყვან შედეგს და ხედავ, ნორმაშია თუ არა, ფერად შკალაზე სად ხვდება და მარტივი ენით რას ნიშნავს. ერთეულებს თვითონ გადაიყვანს (მაგ. მმოლ/ლ და მგ/დლ), ზოგ ანალიზზე სქესსაც ითვალისწინებს. თუ მაჩვენებელი ძალიან გადახრილია, გაფრთხილება ჩნდება. ნორმის დიაპაზონები ტიპური ზრდასრულისთვისაა (ავიღე ADA, ATP III, WHO და Endocrine Society ორიენტირებიდან). ლაბორატორიის ბლანკზე დაწერილი ნორმა უფრო სწორია, ამიტომ ეს გვერდზეც წერია. მონაცემები ფაილში `js/lab-defs.js`-ია.

**ვიზიტისთვის მომზადება (`prep.html`).** ექიმთან წასვლამდე ერთ ფურცელზე აგროვებს საჩივარს, სიმპტომების რუკის ბოლო შედეგს, დღიურის მონაცემებს, შენახულ ანალიზებს და ჯავშანს. სპეციალობის მიხედვით გთავაზობს შეკითხვებს, რომლებიც ექიმს უნდა ჰკითხო. ფურცლის დაბეჭდვა, ტექსტად ჩამოტვირთვა და კოპირება შეიძლება. ყველაფერი ინახება მხოლოდ შენს ბრაუზერში.

**გადაუდებელი რეჟიმი ინტერნეტის გარეშე (`emergency.html`).** ამისთვის დავამატე Service Worker (`sw.js`), რომელიც პირველი ვიზიტისას ინახავს საიტის ყველა ფაილს. შემდეგ ინტერნეტის გარეშეც იხსნება ყველა გვერდი, პირველი დახმარება და CPR მეტრონომი. გვერდზე არის დიდი 112-ის ღილაკი და პირადი ბარათი (სისხლის ჯგუფი, ალერგიები, ახლობლის ნომერი). საიტი ტელეფონზეც შეიძლება დაინსტალირდეს (`manifest.webmanifest`). ეს მუშაობს მხოლოდ HTTPS-ზე ან `localhost`-ზე, GitHub Pages-იც HTTPS-ია.

> თუ ახალ ფაილს დავამატებ პროექტში, მისი სახელი უნდა ჩავწერო `sw.js`-ის `PRECACHE_URLS` სიაში და `CACHE_NAME` გავზარდო (`chaka-v2` → `chaka-v3`), თორემ ოფლაინ რეჟიმში ის ფაილი არ იქნება.

## რა გავაუმჯობესე (ოპტიმიზაცია)

- **სურათები:** ფოტოები JPG-დან WebP-ზე გადავიყვანე და რეალურ ზომამდე დავამცირე (14 ფაილი, 556 KB → 243 KB). თითოეულ `<img>`-ს აქვს `width` და `height`, `loading="lazy"` და `decoding="async"`.
- **სკრიპტები:** ყველა `<script>` არის `defer`. დიდი რუკის ფაილები (`georgia-geo.js`, `map.js`) მთავარ გვერდზე მხოლოდ მაშინ იტვირთება, როცა მინი-რუკა ეკრანთან ახლოვდება. ინგლისური ლექსიკონი (67 KB) მხოლოდ ინგლისურ რეჟიმში იტვირთება.
- **შრიფტები:** Google Fonts არ აჩერებს გვერდის პირველ ჩვენებას.
- **ზედმეტი კოდი:** წავშალე გამოუყენებელი CSS წესი, გამოუყენებელი ცვლადები, ორმაგი JPG ფაილები და ისეთი კოდი, რომელიც მხოლოდ Node-სთვის იყო დატოვებული.
- **სახელები:** გავასწორე ბუნდოვანი სახელები (`el` → `buildElement`, `tr` → `translate` და სხვა).
- **ჩატვირთვის ეკრანი:** მინიმალური ჩვენების დრო 1.7 წამიდან 0.9 წამამდე შევამცირე.
- **ხელმისაწვდომობა:** სათაურების თანმიმდევრობა გავასწორე (h1 → h2 → h3), ღილაკებს დავუმატე `aria-label`.
